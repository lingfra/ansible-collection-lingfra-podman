# Ansible Collection - lingfra.podman

Collection of Ansible content for managing podman containers.

## Installation

This collection is currently in development and not published to [Ansible
Galaxy](https://galaxy.ansible.com).

The collection can be obtained from the Git repository. The following
`requirements.yaml` entry, can be used to download directly from Git:

```yaml
---
collections:
  - name: https://codeberg.org/lingfra/ansible-collection-lingfra-podman
    version: main
    type: git
```

For more information, see the [Installing
collections](https://docs.ansible.com/ansible/latest/collections_guide/collections_installing.html)
section of the Ansible documentation.
